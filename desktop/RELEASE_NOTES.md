## diyalamp 1.3.8

- Make tab hover and the close glyph quieter, balance file row spacing, and soften structural dividers.
- Keep only the grabbed note's label visible while dragging a dot in Connections.
- Use the same sharp lamp mark as the website with a brief shine on hover.
- Slide the selection in filename/text search and Pomodoro, with an instant change when Reduce Motion is enabled.

The Apple silicon and Intel installers include the runtime and matching SHA-256 checksums. They are ad hoc signed. macOS may block first launch until the app is signed with Developer ID and notarized by Apple. See the [installation guide](https://github.com/diyalamp/diyalamp/blob/v1.3.8/docs/install.md) for compatibility and updates.

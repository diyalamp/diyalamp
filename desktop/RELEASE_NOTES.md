## diyalamp 1.3.5

This release restores the JavaFX workspace and its integrated Markdown editor. Read and edit formatted Markdown in the same surface, with local files, note tabs, split view, workspace search, and linked notes.

- The Files, editor, and Connections headers align on a shared divider. Active tabs remain visible in narrow and split editor groups.
- Buttons use consistent geometry across the workspace, dialogs and popovers. Pomodoro groups phase and repeat choices while keeping its durations, icons and keyboard operation.
- Warmer grays improve text contrast. The writing column is narrower in wide windows and the slash menu uses brief entrance motion. macOS Reduce Motion applies to workspace transitions.
- Dense note graphs keep secondary links and labels quiet. Hovering a note shows its direct links and direction arrows without moving the graph. Overlapping titles are hidden until there is room, and the app skips restyling links that stay unchanged.
- Text search results fit their excerpts at both narrow and wide sidebar widths.
- Apple silicon and Intel installers include their Java runtime. The packaging step compares lossless disk image formats and keeps the smallest. No separate Java installation or account is required.

Notes stay in the selected folder as ordinary Markdown. Each installer has a matching SHA-256 checksum. The apps are ad hoc signed and have not been notarized by Apple. See the [installation guide](https://github.com/diyalamp/diyalamp/blob/main/docs/install.md) for first launch and verification.

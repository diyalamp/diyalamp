## diyalamp 1.3.5

This release restores the JavaFX workspace and its integrated Markdown editor. Read and edit formatted Markdown in the same surface, with local files, note tabs, split view, workspace search, and linked notes.

- The Files, editor, and Connections headers align on a shared divider.
- Search and Pomodoro controls center their icons and labels. Blockquotes align their text within the inset panel.
- Empty incoming and outgoing link lists collapse. Visible sections can be resized independently.
- Apple silicon and Intel installers include their Java runtime. The packaging step compares lossless disk image formats and keeps the smallest. No separate Java installation or account is required.

Notes stay in the selected folder as ordinary Markdown. Each installer has a matching SHA-256 checksum. The apps are ad hoc signed and have not been notarized by Apple. See the [installation guide](https://github.com/diyalamp/diyalamp/blob/main/docs/install.md) for first launch and verification.
